# RealityTunnel — Billing/Auth Server

Phase 1.1 foundation. Provides the authentication, subscription management,
and license-signing backend for the RealityTunnel VPN service.

---

## Stack

| Layer | Technology |
|-------|-----------|
| Runtime | Python 3.12 |
| Framework | FastAPI 0.115 |
| Database | PostgreSQL 16 |
| ORM | SQLAlchemy 2.x (async) |
| Driver | asyncpg |
| Migrations | Alembic |
| Validation | Pydantic v2 |
| Settings | pydantic-settings |
| HTTP client | httpx |
| Container | Docker + Compose |

---

## Quick start (Docker Compose)

### 1. Copy and fill the environment file

```bash
cp .env.example .env
# Edit .env — at minimum set POSTGRES_PASSWORD and SECRET_KEY
```

### 2. Start the stack

```bash
docker compose up --build -d
```

### 3. Verify it is healthy

```bash
curl http://localhost:8080/health
```

Expected response:

```json
{
  "status": "ok",
  "components": {
    "postgresql": {
      "status": "ok",
      "latency_ms": 1.23,
      "detail": null
    }
  }
}
```

### 4. Browse the API docs

Open <http://localhost:8080/docs> in your browser.

## Local development (without Docker)

### Prerequisites

- Python 3.12
- PostgreSQL 16 running locally (or via `docker compose up postgres -d`)

### Setup

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate

pip install -r requirements.txt

cp .env.example .env
# Edit POSTGRES_HOST=localhost and set your password
```

### Run the server

```bash
uvicorn app.main:app --reload --port 8080
```

## Database migrations (Alembic)

All Alembic commands must be run from the `billing-server/` directory.

```bash
# Apply all pending migrations
alembic upgrade head

# Create a new autogenerated migration
alembic revision --autogenerate -m "add users table"

# Downgrade one step
alembic downgrade -1

# View current revision
alembic current

# View migration history
alembic history
```

> **Note:** The database URL is read from `.env` at runtime — it is never
> stored in `alembic.ini`.

## Environment variables

| Variable | Default | Description |
|----------|---------|-------------|
| `APP_VERSION` | `1.0.0` | Reported in `/version` |
| `ENVIRONMENT` | `development` | `development` \| `staging` \| `production` |
| `DEBUG` | `false` | Enable SQLAlchemy echo |
| `LOG_LEVEL` | `INFO` | Python logging level |
| `POSTGRES_HOST` | `localhost` | DB host |
| `POSTGRES_PORT` | `5432` | DB port |
| `POSTGRES_DB` | `billing` | Database name |
| `POSTGRES_USER` | `billing` | DB username |
| `POSTGRES_PASSWORD` | — | **Required.** DB password |
| `DATABASE_URL` | — | Full DSN (overrides individual vars) |
| `HOST` | `0.0.0.0` | Uvicorn bind host |
| `PORT` | `8080` | Uvicorn bind port |
| `SECRET_KEY` | — | **Required in prod.** App secret |

│   ├── main.py            # FastAPI app, lifespan, root routes
